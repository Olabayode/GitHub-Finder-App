# GitHub Finder

GitHub Finder is a React application built with Create React App that allows users to search for GitHub profiles using the GitHub API. Users can explore developer profiles and view useful account information such as followers, repositories, bio, location, and more.

## Features

- Search for GitHub users
- View detailed GitHub profile information
- Display followers and following count
- View public repositories
- Responsive and clean user interface
- Real-time data fetched from the GitHub API

## Built With

- React.js
- Create React App
- JavaScript
- HTML5
- CSS3
- GitHub REST API
